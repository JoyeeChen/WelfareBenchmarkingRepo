# Agent Evals Prototyping Folder

We are creating evals, _for AI agents specifically_, of how well agents recognize and mitigate harms related to animal welfare. Both direct harms (i.e. going on elephant tours) and indirect/downstream harms (i.e. suggesting meat recipes for a cookout) are considered.

We immensely thank the team at AHB (Animal Harm Bench, https://github.com/UKGovernmentBEIS/inspect_evals/tree/main/src/inspect_evals/ahb) for their benchmark questions which inspired our agent evals scenarios.
